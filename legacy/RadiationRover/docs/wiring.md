# توصيلات RadiationRover — المرجع الكامل

> حدّث هذا الملف في نفس الجلسة عند أي تغيير منفذ. أرقام المنافذ في الكود تأتي من `config.h` حصراً.

## 1. الهَب — ESP32-S3 DevKitC N16R8 (فلاش 16MB، PSRAM 8MB)

> الخريطة مثبتة عملياً من السكتش المرجعي `firmware/reference/gps_bno055_sd_logger_final.ino`.

| الوظيفة | المنفذ | ملاحظات |
|---------|--------|---------|
| جيجر أنبوب 1 | GPIO **4** | مقاطعة **RISING**، `INPUT` عائم (CAJOE/J305) — ⚠ **انقل السلك من 15 إلى 4** |
| جيجر أنبوب 2 | GPIO 5 (مبدئي) | لم يصل بعد — `SINGLE_TUBE_MODE=1` |
| GPS NEO-6M/7M/8M | RX=**16** ← GPS TX فقط | Serial1، 9600 baud، تغذية 3V3 — TX غير موصول |
| BNO055 (IMU) | SDA=**21**، SCL=**9** | ⚠ **ممنوع SCL على 20**: GPIO20 = USB D+ في S3، يقتل I2C عند التوصيل عبر USB (فشل حقيقي موثق) |
| كرت SD (SPI) | SCK=**12**، MOSI=**11**، MISO=**13**، CS=**10** | عبر `SPIClass spiSD(FSPI)` ثم `SD.begin(CS, spiSD)` |
| لورا HC-14 | TX=17 → HC-14 RX، RX=18 ← HC-14 TX | ✅ UART2، 9600، تحكم يدوي أولوية قصوى |
| الطاقة | VIN=5V أو USB | |

> **حساسات العوائق ليست على الهَب** — هي على شيلد الأردوينو (§3، §5.2). الهَب يستقبل قراءتها جاهزة عبر UDP 4212.

### ⚠ قيود منافذ ESP32-S3 (N16R8) — لا تستخدم أبداً:
- **19 و20**: USB D-/D+ المدمج (البرمجة والمونيتور) — استخدامها يعطّل USB أو الطرفية الموصولة عليها.
- **26–32**: ناقل الفلاش الداخلي (SPI0) — أي استخدام يفشّل الإقلاع. (لهذا نُقل الجيجر من 32!)
- **33–37**: ناقل PSRAM الثماني في N16R8 تحديداً.

⚠ لا يوجد توصيل سلكي بين الهَب والروبوت — التواصل عبر WiFi (UDP) مع ESP32-CAM.

## 2. ESP32-CAM (AI Thinker)

- موصولة فيزيائياً بالأردوينو عبر Serial المشترك (115200) — نفس منفذ الرفع، افصلها عند رفع كود للأردوينو.
- منافذ الكاميرا الداخلية قياسية (AI Thinker) — معرفة في `esp32cam_bridge.ino`.
- LED فلاش على GPIO 4 (يُستخدم كمؤشر أعطال).

## 3. Arduino Uno R3 + شيلد GalaxyRVR

| الوظيفة | المنفذ |
|---------|--------|
| محركات يسار (3 عجلات كمجموعة) | IN1=2، IN2=3 |
| محركات يمين (3 عجلات كمجموعة) | IN3=4، IN4=5 |
| جهد البطارية | A3 (مقسّم جهد ×2، بطاريتا 18650) |
| فوق-صوتي أمامي | **10** (TRIG+ECHO سلك واحد) |
| IR عائق يسار | **8** (LOW عند عائق) |
| IR عائق يمين | **7** (LOW عند عائق) |

- **الشيلد يتحكم بالمحركات كمجموعتين (يسار/يمين) فقط** — لا تحكم فردياً بالعجلات.
- ثابت `MOTORS_SWAP_LR` في `arduino_rover.ino` يعكس الجهتين برمجياً إن كان التوصيل معكوساً.
- الحركة: أمام = IN1+IN4، خلف = IN2+IN3، دوران بالمكان = جهة أمام + جهة خلف.

## 4.1 وصلة لورا HC-14 (شاشة ↔ هَب) — طرفاً طرفاً

> قناة تحكم يدوية لاسلكية طويلة المدى بين الشاشة والهَب، **أولوية قصوى** (تعمل حتى لو
> انقطع WiFi). HC-14 جسر سيريال شفاف: ما يدخل UART أحدهما يخرج من UART الآخر.

| طرف HC-14 على **الهَب (S3)** | ↔ | طرف HC-14 على **الشاشة (3.5")** |
|------------------------------|---|-------------------------------|
| VCC → 3.3V (أو 5V حسب الوحدة) | | VCC → 3.3V |
| GND → GND | | GND → GND |
| RXD ← الهَب TX **GPIO17** | | RXD ← الشاشة TX **GPIO22** |
| TXD → الهَب RX **GPIO18** | | TXD → الشاشة RX **GPIO21** |
| SET | يُترك حراً (وضع شفاف) | SET يُترك حراً |

- على الشاشة استخدم **موصل 3.3V نفسه الذي عليه GPIO21/22** لتغذية HC-14 وربط بياناته.
- **الباود 9600 على الطرفين** (`LORA_BAUD`)، ويجب أن يكون **إعداد قناة/تردد HC-14 متطابقاً** على الوحدتين (الافتراضي من المصنع متطابق عادةً؛ وإلا اضبطهما بأوامر AT عبر منفذ SET).
- ⚠ **لا تعكس RX/TX**: TX وحدة → RX الأخرى.

## 5. عداد الجيجر المزدوج

- أنبوب 1 على GPIO **4** (نبضة موجبة، RISING عائم)، أنبوب 2 لم يصل (GPIO 5 مبدئياً).
- درع رصاص جزئي حول الأنبوبين يعطي حساسية اتجاهية — أساس المسح الدوراني 360°.
- التحويل: µSv/h = CPM ÷ **111** (مُعاير ضد Cs-137 مرجعي 2026-07 — `CPM_PER_USVH`).
- **الزمن الميت**: يُصحَّح على القراءة الحقيقية قبل التحويل (`GEIGER_DEADTIME_TAU_S=200µs`).
- **وضع الأنبوب الواحد** (`SINGLE_TUBE_MODE=1`، المرحلة B1): أنبوب 1 حقيقي فقط،
  أنبوب 2 معطَّل حتى وصوله (قلب العلم إلى 0 يعيد الوضع المزدوج).

## 5.1 توصيل القطع الجديدة — المرحلة B1 (طرفاً طرفاً)

> ⚠ **حرج**: وحّد الأرضي (GND) بين اللوحتين والـESP32 — بلا أرضي مشترك تكون
> النبضات وقراءات I2C بلا مرجع جهد (عدّ عشوائي / فشل I2C). كلتا اللوحتين تُغذّى **3.3V**.

### لوحة جيجر CAJOE — هيدر P3 (ثلاثة أطراف)

| طرف P3 | ← منفذ ESP32 | ملاحظة |
|--------|--------------|--------|
| **VIN** (النبضات) | GPIO **4** | نبضة موجبة — مقاطعة **RISING**، `INPUT` عائم، ISR يعدّ فقط (كان 15) |
| **5V** (تغذية اللوحة) | **3V3** | ⚠ **3.3V وليس 5V** — لإبقاء ذروة النبضة آمنة على منفذ ESP32 |
| **GND** | **GND** | أرضي مشترك إلزامي |

> ⚠ **مؤكد على العتاد (SentinelLab، نفس اللوحة)**: خرج VIN نبضة موجبة ضعيفة من مخرج
> عالي الممانعة. **ممنوع أي مقاومة** رفع/سحب (داخلية أو خارجية) — كلها تقتل الإشارة (CPM=0).
> لذلك أنبوب 1 = `INPUT` عائم + `RISING` (وليس `INPUT_PULLUP`/`FALLING`).

### BNO055 (IMU)

| طرف اللوحة | ← منفذ ESP32 | ملاحظة |
|-----------|--------------|--------|
| **VIN** | **3V3** | التغذية 3.3V |
| **GND** | **GND** | أرضي مشترك إلزامي |
| **SDA** | GPIO **21** | I2C data |
| **SCL** | GPIO **20** | I2C clock — (ليس 22: غير متوفر على اللوحة) |
| PS0 / PS1 / INT / ADR | — | تُترك غير موصولة (الافتراضي I2C، العنوان 0x28) |

- الوضع: NDOF (دمج مغناطيسي/جيروسكوب/تسارع) — heading مطلق.
- المعايرة: لوّح بالجهاز على شكل ∞ حتى يبلغ mag ≥ 2 (مؤشرات s/g/a/m في الواجهة).

## 5.2 حساسات العوائق (فوق-صوتي + IR ×2) — على شيلد GalaxyRVR

> الحساسات موصولة بمنافذ الأردوينو عبر موصلات الشيلد الجاهزة (توصيل SunFounder
> الرسمي — لا سلك يدوي). الأردوينو يقرأها ويرسلها فقط؛ **لا يتخذ أي قرار** (يبقى
> سائق محركات). مسار البيانات: أردوينو → Serial → كام → **UDP 4212** → الهَب.

| الحساس | منفذ الأردوينو | القراءة |
|--------|----------------|---------|
| فوق-صوتي أمامي | **10** (TRIG وECHO سلك واحد) | نبضة 10µs ثم `pulseIn` بمهلة 18ms (≈300سم)؛ سم = µs × 0.017 |
| IR عائق يسار | **8** | `digitalRead==LOW` = عائق |
| IR عائق يمين | **7** | `digitalRead==LOW` = عائق |

- المنافذ معرّفة في `firmware/arduino_rover/arduino_rover.ino`، والعتبات في `config.h` بالهَب (`OBSTACLE_WARN_CM=50`، `OBSTACLE_NEAR_CM=20`).
- الأردوينو يقرأ ويرسل كل 200ms بصيغة `OBS:<سم>,<L>,<R>` (المسافة -1 = خالٍ/خارج المدى).
- الهَب يبلّغ الحالة "لا بيانات" (شريحة OBS حمراء) إن لم يصل `OBS:` خلال `OBSTACLE_STALE_MS` (فصل الأردوينو/الكام أو انقطاع WiFi) — لا محاكاة.
- **الإيقاف الطارئ عند عائق** (`OBSTACLE_ESTOP`) **مطفأ افتراضياً**: البيانات تصل عبر WiFi فلا تصلح كسلامة صلبة، وكي لا يقاطع القيادة اليدوية/الرجوع.

## 6. ملاحظات طاقة

- بطارية الروبوت: 2×18650 (8.4V ممتلئة، 6.0V فارغة) تغذي الشيلد والأردوينو والكام.
- الهَب يفضَّل تغذيته من منظم 5V مستقل عن ضجيج المحركات.
- عتبة RTH المخططة: < 6.4V (المرحلة A4).
