## ١. الاتجاه: BNO055 → MPU-6050

### ما حدث

BNO055 تعرّضت لـ **5.40V** بينما حدها المطلق **3.6V**. النتيجة: انهيار مشغّلات الخرج، فصارت تشدّ خطي `SDA` و `SCL` للأرضي وتشلّ الناقل بالكامل.

**التشخيص المؤكِّد** (مفيد لو تكرر مع أي جهاز I2C):

| الحالة | `pinctrl get 6,7` | `i2cdetect` |
|---|---|---|
| لا شيء موصول | `hi` `hi` | فاضي |
| MPU-6050 (سليم) | `hi` `hi` | ظهر `0x68` |
| BNO055 (تالف) | **`lo` `lo`** | **117 عنواناً وهمياً** |

> **قاعدة عامة:** لو ظهر الناقل ممتلئاً بكل العناوين `0x03`–`0x77`، فهذه ليست أجهزة — هذا خط SDA مشدود للأرضي. لا تعامله كاكتشاف.

### البديل الحالي

```
الشريحة:   MPU-6050 (GY-521)
الناقل:    /dev/i2c-4   (GPIO6=SDA دبوس 31، GPIO7=SCL دبوس 26)
العنوان:   0x68
WHO_AM_I:  0x75 → يرجع 0x68
معدل القراءة المقاس: 39.7 Hz
```

**طرف AD0:** يعمل معلّقاً، لكن **يجب ربطه بالأرضي** — طرف عائم في روبوت يهتز قد يقفز بالعنوان إلى `0x69` عشوائياً.

### الفارق الوظيفي — حرج

| | BNO055 (السابق) | MPU-6050 (الحالي) |
|---|---|---|
| المحاور | 9 | **6** |
| مغنيتومتر | موجود | **لا يوجد** |
| معالج دمج داخلي | Cortex-M0 | **لا يوجد** |
| الخرج | heading جاهز بالدرجات | بيانات خام فقط |
| مرجع مطلق | موجود | **لا يوجد** |

**النتيجة:** الاتجاه المطلق ينحرف بلا حد. لا يوجد ما يصحّحه.

### قياس الانحياز الفعلي

```
gyro bias:  X = -2.76   Y = -1.78   Z = -0.06  °/s
accel magnitude at rest: 1.031 g
```

**محور Z هو المهم** (الدوران الأفقي = yaw). الانحياز `-0.06 °/s` منخفض بشكل ممتاز ≈ **3.6 درجة انحراف في الساعة** بعد الطرح.

### المعايرة — إلزامية عند كل إقلاع

الانحياز يتغيّر مع الحرارة. لا تستخدم قيماً محفوظة.

```python
def calibrate_gyro(read_fn, samples=2000):
    """اللوحة ساكنة تماماً. يرجع الانحياز بالدرجة/ثانية."""
    s = [0.0, 0.0, 0.0]
    for _ in range(samples):
        g = read_fn()
        for i in range(3):
            s[i] += g[i]
        time.sleep(0.002)
    return [v / samples for v in s]
```

### القراءة

```python
from smbus2 import SMBus
import time

MPU_BUS, MPU_ADDR = 4, 0x68

bus = SMBus(MPU_BUS)
bus.write_byte_data(MPU_ADDR, 0x6B, 0)   # wake from sleep
time.sleep(0.1)

def _rd(reg):
    hi = bus.read_byte_data(MPU_ADDR, reg)
    lo = bus.read_byte_data(MPU_ADDR, reg + 1)
    v = (hi << 8) | lo
    return v - 65536 if v > 32767 else v

def read_accel():   # g
    return [_rd(r) / 16384.0 for r in (0x3B, 0x3D, 0x3F)]

def read_gyro():    # °/s
    return [_rd(r) / 131.0 for r in (0x43, 0x45, 0x47)]
```

| السجل | المحتوى | المعامل |
|---|---|---|
| `0x3B` | ACCEL_X..Z (6 بايت) | ÷ 16384 → g |
| `0x41` | TEMP | ÷ 340 + 36.53 → °C |
| `0x43` | GYRO_X..Z (6 بايت) | ÷ 131 → °/s |
| `0x6B` | PWR_MGMT_1 | اكتب 0 للإيقاظ |
| `0x75` | WHO_AM_I | يرجع 0x68 |

### ما ينجح وما يفشل

| المهمة | الحكم |
|---|---|
| السير المستقيم بحلقة تحكّم | ✅ ممتاز — التصحيح لحظي قبل تراكم الخطأ |
| لفّة 90° محسوبة | ✅ خطأ ~1° |
| الاتجاه المطلق بعد 10 دقائق | ❌ بلا معنى |
| العودة لنقطة البداية بالحساب الميت | ❌ ينحرف |
| المسح الدوراني بمرجع ثابت | ❌ ينحرف |

**السير المستقيم** يعمل لأن الجيرو يقيس **معدل** الدوران، والتصحيح يحدث فوراً:

```python
error = heading_now - heading_target
correction = KP * error
left  = base_power - correction
right = base_power + correction
```

### خيارات استعادة الاتجاه المطلق

1. **`0x0c` على الناقل 1** — يُرجَّح أنه مغنيتومتر (QMC5883L). **غير معرَّف بعد.** لو تأكد، يحل المشكلة بلا شراء.
2. **QMI8658 داخل Wave Rover** — التغذية الراجعة تُرجع حقل `"y"` (yaw). ملف التوثيق يقول إنه معطّل، لكن **يستحق إعادة الفحص**.
3. **BNO085** — الحل الأمثل (انحراف 0.5°/دقيقة، دمج داخلي). قيد الطلب.
4. **GPS** — اتجاه مطلق أثناء الحركة فقط، لا عند الدوران في المكان.

## ٢. مراقبة البطارية — INA219

### الموقع الفعلي

```
الشريحة:   INA219 على بورد Waveshare UPS Module 3S
الناقل:    /dev/i2c-1   ← لا الناقل 4
العنوان:   0x42          ← لا 0x41
مقاومة القياس: 0.01 Ω
```

> **تحذير:** جدول سابق في الكود يعلن `0x41` على الناقل 1. **خطأ.** الفحص المباشر أثبت `0x42`، بدليل قاطع: قراءة سجل الإعدادات رجعت `0x399f` — نفس القيمة المكتوبة — وجهد 10.74V داخل نطاق 3S.

### السائق

```python
from smbus2 import SMBus
import time

INA_BUS, INA_ADDR, SHUNT_OHM = 1, 0x42, 0.01

class UPS:
    def __init__(self):
        self.bus = SMBus(INA_BUS)
        # 0x399F = مدى 32V، PGA ÷8 (±320mV)، ADC 12-bit، قياس مستمر
        self.bus.write_i2c_block_data(INA_ADDR, 0x00, [0x39, 0x9F])
        time.sleep(0.1)

    def _signed(self, reg):
        d = self.bus.read_i2c_block_data(INA_ADDR, reg, 2)
        v = (d[0] << 8) | d[1]
        return v - 65536 if v > 32767 else v

    def read(self):
        raw = self._signed(0x02)
        overflow = bool(raw & 1)          # بت 0 = OVF
        volts = (raw >> 3) * 0.004        # بتات 15..3، خطوة 4mV
        amps = (self._signed(0x01) * 0.00001) / SHUNT_OHM   # خطوة 10µV
        return {
            "volts": volts,
            "per_cell": volts / 3.0,
            "amps": amps,
            "watts": volts * abs(amps),
            "charging": amps > 0.05,
            "overflow": overflow,
        }
```

### شرح السجلات

| السجل | المحتوى | المعالجة |
|---|---|---|
| `0x00` | CONFIG | اكتب `0x399F` مرة عند البدء |
| `0x01` | SHUNT_VOLTAGE | × 10µV، ثم ÷ 0.01Ω → أمبير |
| `0x02` | BUS_VOLTAGE | **أزح 3 بتات يميناً** ثم × 4mV |

**البتات الثلاث السفلية في `0x02` ليست جهداً** — بت 1 = CNVR (اكتمل التحويل)، بت 0 = OVF (تجاوز). بدون الإزاحة تحصل على رقم أكبر ثمانية أضعاف.

مثال: `0x57D0` → إزاحة 3 → `2810` → × 0.004 → **11.24V**

### قراءات مؤكَّدة

```
11.34 V  (3.78 V/خلية)   +0.639 A شحن   7.24 W   ~65%
```

### عتبات 3S

| الجهد | لكل خلية | التصرف |
|---|---|---|
| 12.60 | 4.20 | ممتلئة — افصل الشاحن |
| 10.50 | 3.50 | ارجع للشحن |
| 10.20 | 3.40 | أوقف المحركات، توجّه للشحن |
| **9.60** | **3.20** | **أطفئ فوراً** |
| ~8.4 | 2.80 | قطع الحماية — انقطاع مفاجئ |

### الإيقاف الآمن

```python
V_CRITICAL, V_WARN = 9.6, 10.2
low_count = 0

r = ups.read()
if r["volts"] < V_CRITICAL and not r["charging"]:
    low_count += 1
    if low_count >= 5:          # 5 قراءات متتالية
        os.system("sudo shutdown -h now")
else:
    low_count = 0
```

**اضبط على الجهد لا النسبة** — الجهد قياس مباشر، النسبة محسوبة تقديرياً.

**اشترط قراءات متتالية** — تيار المحركات يسبب هبوطاً لحظياً لا يستحق إطفاء الروفر.

**استثنِ حالة الشحن** — الجهد أثناء الشحن مضلّل.

### النسبة — تحذير

المعادلة الخطية `(V-9)/3.6` تقريبية وتضلّل في الأطراف. منحنى الليثيوم مسطّح في الوسط وينهار بسرعة في النهاية. والجهد **ينخفض تحت الحمل** — 0.3-0.5V عند تشغيل المحركات.

بديل أدق:

```python
CURVE = [(12.60,100), (12.20,90), (11.90,75), (11.60,60),
         (11.30,45), (11.00,30), (10.60,18), (10.20,8), (9.00,0)]
R_INTERNAL = 0.15   # عايِرها تجريبياً: R = ΔV / I

def percent(volts, amps):
    v = volts + abs(amps) * R_INTERNAL      # تعويض هبوط الحمل
    if v >= CURVE[0][0]: return 100.0
    if v <= CURVE[-1][0]: return 0.0
    for (v1,p1),(v2,p2) in zip(CURVE, CURVE[1:]):
        if v2 <= v <= v1:
            return p2 + (v - v2) * (p1 - p2) / (v1 - v2)
    return 0.0
```

### ⚠ مصدر الجهد — غير محلول

قياسات سابقة أظهرت **5.40V** و **4.70V** على خط الـ 5V. المواصفة **4.75–5.25V**.

- 5.40V هي التي **قتلت BNO055**
- 4.70V تحت الحد الأدنى لاستقرار الباي 4 → أخطاء I2C متقطعة

**لم يُقَس خرج Type-C تحت حمل بعد.** هذا بند مفتوح وحرج. INA219 يقرأ حزمة البطاريات (9-12.6V) لا خط الـ 5V، فلا يكشف هذه المشكلة.

المنطق: **`0` = عائق**. التغذية **3.3V**. تُقرأ بـ `SET_PULL_UP`.

### فخ تشخيصي مهم

**منفذ غير موصول يقرأ `clear` أيضاً** — بسبب الشدّ المرتفع الداخلي. لا يمكن التمييز بين حسّاس سليم وسلك مقطوع إلا بالتلويح الفعلي أمامه.

أي فحص ذاتي يجب أن يتضمن مرحلة تفاعلية، لا قراءة لحظية فقط.

### المعايرة

كل وحدة فيها **مقاومة متغيّرة زرقاء** تضبط المدى. اضبطها على **25-30 سم** بدل الافتراضي (~10 سم).

المبرر: عند 0.6 م/ث، الفرق بين 10 و 30 سم هو **0.33 ثانية** إضافية لزمن الاستجابة.

### الموضع ومنطق التفادي

الحسّاسان الأصليان في **الركنين الأماميين**، كلاهما يراقب الأمام بزاوية:

```
عائق أمام-يسار  → لفّ يميناً
عائق أمام-يمين  → لفّ يساراً
كلاهما / مركزي  → رجوع + لفّ 90°
```

الثلاثة الجديدة تحتاج تعريف موضع قبل توسيع المنطق. التسميات الحالية افتراضية.

### لماذا IR إلزامي لا احتياطي

الألترا سونيك يعمى عن: الأسطح المائلة (الموجة ترتد بعيداً) · المواد الماصّة (قماش، إسفنج) · الأجسام المنخفضة أو خارج شعاعه الضيق (~15°).

IR يمسك هذه الحالات. **تكامل لا تكرار.**

## قيود لا تتجاوزها القيادة الذاتية

### ⚠ التفاف قوة فيرموير Wave Rover

**غير موثّق رسمياً من Waveshare.** أي قوة **فوق 0.5** يطرح منها الفيرموير 0.5:

| المرسل | السرعة المقاسة | الفعّال |
|---|---|---|
| 0.5 | 0.750 م/ث | 0.5 ✓ |
| 0.6 | 0.100 م/ث | 0.1 ✗ |
| 0.8 | 0.410 م/ث | 0.3 ✗ |
| 1.0 | 0.750 م/ث | 0.5 ✗ |

**الخطر الصامت:** إرسال 0.6 توقعاً لسرعة أعلى يُنتج زحفاً بطيئاً، بينما يحسب `deadreckoning` المسافة على السرعة المتوقَّعة → **انحراف كبير في الموقع بلا إنذار**.

**الحماية:** `MAX_MOTOR_POWER = 0.5` وقصّ صارم في `WaveRoverBridge.motors()` بعد `MOTOR_INVERT`، مع تسجيل تحذير. كل مسارات الإرسال تمرّ عبرها.

**العلاقة الصالحة:** السرعة ≈ **1.5 × القوة**، ضمن **0.1–0.5 فقط**. لا استقراء خارجها.

### ⚠ الاتجاهات معكوسة عتادياً

`MOTOR_INVERT = -1` — أمر L/R موجب يعني **للخلف**.

### ⚠ ارتفاع تثبيت الألترا سونيك

تثبيت منخفض يجعل الحافة السفلى لمخروط الشعاع (±7.5°) تصطدم بالأرض → **21 سم ثابتة والروبوت ساكن**.

التوقيع: **عنقودان ضيّقان** (21سم و182سم) بنسبة 84%/15% — لا تشتّت عشوائي كالضجيج.

الأثر: سلّم السلامة يتشنّج بين «توقف» و«طريق مفتوح»، فينزلق الروبوت وتُعلَّم خلايا سليمة محجوبة خطأً.

**لا يُعالَج برمجياً:** أي مرشّح يتجاهل ما دون 30سم يُعمي طبقة السلامة عن العوائق القريبة الحقيقية — وهي أخطر ما تحرسه. **الحل تثبيت لا كود.**

### ⚠ توزيع الأمان

منطق النجاة الفوري **لا يسكن الراسبري**. مهلة توقف المحركات في ESP32 الروفر. الراسبري قد يتجمد فيفشل النظام آمناً بدونه.

**فقدان heartbeat > 1.5 ثانية يوقف المحركات.**

## ملاحظة منهجية

خطأ متكرر كلّف عدة ساعات: **الاعتماد على أرقام منافذ من التوثيق دون التحقق الفيزيائي.**

سلك على الدبوس 26 كان فعلياً على دبوس مجاور، وأدى لتشخيص خاطئ بأن حسّاساً سليماً كان تالفاً.

**طريقة التحقق:**

```bash
watch -n 0.2 pinctrl get <BCM>
```

ثم لمس الدبوس بسلك أرضي — القراءة تنزل `lo` فوراً إن كان الدبوس صحيحاً.

وبالمثل: **قِس الجهد على أطراف اللوحة نفسها، لا على الهيدر.** الفرق بين 3.3V و 5.4V هو الفرق بين قطعة تعمل وقطعة محروقة.
