# دليل التشغيل على الراسبري — منصّة Freenove

> كل أمر هنا **منسوخ من الكود لا مفترَض** (تُحقّق 2026-09-12).
> الأسماء والوسائط مطابقة لـ`--help` الفعلي لكل سكربت.

## ⚠ ثلاث قواعد تسري على كل خطوة

1. **البيئة الافتراضية**: كل أمر `python3 -m pi.…` يلزمه
   `source venv/bin/activate` أولاً. (`./run_server.sh` يفعّلها بنفسه.)
2. 🔴 **أوقف السيرفر قبل أي سكربت يمسك عتاداً**: السيرفر يحجز ناقل I2C
   ومصدر الاتجاه، ومنازعته تُنتج قراءات خاطئة **بلا رسالة خطأ**.
   ```bash
   pkill -f "pi.web.server" ; sleep 1
   ```
3. 🔴 **لا سكربت يسقط إلى المحاكاة بصمت**: إن طبع `الوضع: sim` فالعتاد
   لم يُفتح — **أوقف وأصلح**، ولا تُكمل. أي رقم من المحاكاة يُكتب في
   config ثم يقود محركات حقيقية.

## أ) التثبيت — ما الذي أثبّته؟

```bash
cd ~/RMS-Rover-v2
git checkout freenove-chassis
./setup_pi.sh          # apt + venv + requirements + I2C + dtoverlay
```

يفعل: `python3-lgpio` و`i2c-tools` عبر apt · بيئة `venv` بـ
`--system-site-packages` · `pip install -r requirements.txt` ·
تفعيل I2C · وإضافة `dtoverlay=i2c4,pins_6_7,baudrate=100000`.

| ماذا نحتاج | لماذا |
|---|---|
| `smbus2` | سائق **كل** عتاد I2C: PCA9685 (محركات) · INA219 (بطارية) · MPU |
| `lgpio` | الجيجر (`pigpio` محذوف من trixie) — عبر apt لا pip |
| `i2c-tools` | `i2cdetect` للفحص |
| `pyserial` | دونقل LoRa |
| `opencv-python-headless` | الكاميرا |

🔴 **لا مكتبة Freenove**: سائق PCA9685 **مُضمَّن** في
`pi/rover/pca9685.py` (~30 سطراً). لا تُثبّت شيئاً من Freenove ولا
تنسخ مجلّد `reference/` — تبعية على مجلّد غير مُتتبَّع تكسر البناء.

**الناقلان**: `i2c-1` (تلقائي عبر raspi-config) و`i2c-4` (يلزمه
الـoverlay). **بلا SPI ولا overlay آخر** — كل إرث UART سقط مع Wave Rover.

```bash
sudo reboot            # ⚠ إلزامي بعد إضافة الـoverlay
ls /dev/i2c-*          # ✅ المتوقع: /dev/i2c-1  /dev/i2c-4
```

**الفشل**: `i2c-4` غائب ⇒ السطر لم يُكتب أو لم تُعد الإقلاع. تحقّق:
`grep i2c4 /boot/firmware/config.txt`

## ب) الفحص قبل أي حركة

```bash
i2cdetect -y 1         # المحركات + البطارية
i2cdetect -y 4         # وحدة الاتجاه
```

| الناقل | العنوان المتوقع | القطعة | الفشل يعني |
|---|---|---|---|
| 1 | **`40`** | PCA9685 (محركات Freenove) | اللوحة غير مُغذّاة أو SDA/SCL مقلوبان |
| 1 | **`42`** | INA219 (بطارية الراسبري) | UPS غير موصولة — ليست حاجباً للحركة |
| 4 | **`68`** | وحدة MPU | GPIO6/7 أو الـoverlay |

🔴 **`40` غائب = لا حركة إطلاقاً.** لا تُكمل — افحص تغذية لوح Freenove
(بطاريته الخاصة) والأسلاك.

⚠ ظهور العنوان يعني **الشريحة تردّ**، لا أن الكتابة تثبت. (درس مقاس:
وحدة مقلَّدة ردّت بهوية صحيحة ولم تحتفظ بأي كتابة.)

**تأكيد أن الكود يراها** — بلا حركة:
```bash
source venv/bin/activate
python3 -c "
from pi.rover.bridge import RoverControlBridge as B
b = B(mode='real')
print('المنصّة:', b._tp.name, '| الوضع:', b.mode)
print('الناقل سليم:', b.link_ok, '| خريطة المحركات مشتقّة:', b._tp.motor_map_calibrated)
b.close()"
```
✅ المتوقع: `الوضع: real` · `الناقل سليم: True` ·
`خريطة المحركات مشتقّة: False` ← **طبيعي الآن**، تُشتقّ في (د).

## ج) أبسط أمر يحرّك المحركات

> ⚠⚠ **ارفع العجلات عن الأرض** في أول تشغيل: خريطة المحركات لم تُشتقّ
> بعد، فقد يتحرّك عكس المتوقَّع أو يدور بالمكان.

```bash
source venv/bin/activate && python3 -c "
from pi.rover.bridge import RoverControlBridge as B
import time
b = B(mode='real'); b.forward(0.3); time.sleep(2); b.stop(); b.close()
print('تمّ')"
```

يمرّ بـ`motors()` — المسار الوحيد للإرسال — فيُطبَّق حاجز
`MAX_MOTOR_POWER` ويُسجَّل الأمر.

| المشاهدة | المعنى |
|---|---|
| كل العجلات تدور 2ث ثم تقف | ✅ الناقل والتغذية سليمان |
| لا شيء يدور | التغذية أو `40` غائب — ارجع إلى (ب) |
| بعضها يدور | أسلاك عجلة/قناة — **لا يصلحه أي ثابت** |
| تدور ثم لا تقف | اقطع الطاقة يدوياً، وأبلغني |

## د) الاتجاهات الأربعة + اشتقاق `MOTOR_INVERT`

🔴 **الترتيب مهم**: اشتقّ أولاً بالمسبار، ثم تحقّق. عكسه يقيس نفسه.

### د-1 — اشتقاق الخريطة (الروبوت **مرفوع**)
```bash
python3 -m pi.tests.probe_motor_map
```
نبضتان — الحقل `L` وحده ثم `R` وحده — وبعد كلٍّ سؤالان:
- أي جهة دارت؟ `g` = جهة أنبوب الجيجر · `o` = المقابلة · `n` = لا شيء
- ونحو أين؟ `f` = مقدّمة الروبوت · `b` = مؤخرته

⚠ **لا تستعمل يمين/يسار**: تنعكس بموقع الواقف. المعلم الفيزيائي وحده.

المخرج وصفة: `MOTOR_SWAP_LR = …` و`MOTOR_INVERT = …` → اكتبها في
`pi/config.py`.

| مخرج | معنى |
|---|---|
| `✅ الوصفة النهائية` | انسخ القيمتين |
| `🔴 حقل بلا استجابة` | جانب ميت — راجع `FREENOVE_WHEEL_CHANNELS` والتغذية |
| `🔴 الحقلان يحرّكان الجهة نفسها` | خطأ خريطة قنوات لا قطبية |
| `🔴 قطبية الجانبين مختلفة` | انعكاس محرّك واحد (أسلاك) — **لا يصلحه ثابت** |

### د-2 — التحقق (الروبوت **على الأرض**، مساحة خالية)
```bash
python3 -m pi.tests.check_directions --power 0.25
```
✅ تقدّم للأمام · رجوع للخلف · لفّ يمين/يسار **مشاهَداً من خلف الروبوت**.

⚠ **لفّة 90° لا 180°**: الـ180 تنتهي مواجهةً نفس الجهة في الاتجاهين
فتعمى عن الانعكاس.

🔴 **إن دار عكس المطلوب: لا تلمس `MPU6050_GYRO_Z_SIGN`.** قيست باليد
بلا محركات فهي مستقلة عن قطبية المحركات. لمسها يعيد فخّ «الخطأين
المتلازمين» — يُلغيان بعضهما فيصمت حارس `sign_mismatch` ويعيش الخطأ
شهراً. أعد (د-1).

## هـ) المعايرة — بالترتيب

### هـ-1 · صحّة MPU (بلا حركة أولاً)
```bash
python3 -m pi.tests.check_imu_health --seconds 30
python3 -m pi.tests.check_imu_health --motors --pulses 6 --power 0.3   # ⚠ يحرّك
```
✅ القراءات تتغيّر · لا «صفر مضبوط» · `recoveries` يبقى 0.
🔴 تصاعد `recoveries` مع كل إقلاع محركات = **التغذية تنهار فعلاً** ⇒
إصلاح عتادي (مكثّف تفريغ عند الحسّاس، وفصل تغذيته عن خط المحركات).

### هـ-2 · إشارة محور Z — 🔴 **باليد بلا محركات**
```bash
python3 -m pi.tests.calibrate_mpu6050 --only sign
```
تُدير الروبوت **بيدك** يميناً ~90°. ✅ الإشارة المطبوعة تطابق جهة اليد.
⚠ قياسها **بالمحركات** يعطي حاصل ضرب الخطأين فتبدو سليمة وهي معكوسة.

### هـ-3 · أرضية الضجيج والانحراف
```bash
python3 -m pi.tests.calibrate_mpu6050 --only noise --noise-s 60
python3 -m pi.tests.calibrate_mpu6050 --only drift --drift-min 10
```
✅ σ المتوقعة ~0.0245°/ث ⇒ `HEADING_DEADBAND_DPS = 3σ ≈ 0.10`.
🔴 σ أكبر بكثير = اهتزاز تركيب أو تغذية — **لا توسّع العتبة تعويضاً**:
العتبة الواسعة تبتلع دوراناً حقيقياً بطيئاً.

### هـ-4 · جدول الأرض: قوة → سرعة
```bash
python3 -m pi.tests.calibrate_speed --powers 0.20 0.30 0.40 --seconds 3
```
يسير، وتقيس أنت المسافة **بشريط قياس** وتُدخلها. المخرج يعطيك
`FREENOVE_SPEED_PER_POWER` و`DRIVE_SPEED_MPS` جاهزين لـconfig.
⚠ **ببطارية مشحونة** · مساحة خالية · بلا أي تفادٍ.
🔴 مسافة صفر = لم يتحرّك ⇒ ارجع إلى (د).

### هـ-5 · `GYRO_SCALE` — ⚠ **بـ180° لا 90°**
```bash
python3 -m pi.tests.calibrate_heading --stage 2 --angle 180 --trials 3
```
🔴 **تصحيح لطلبك**: الـ90° تلزم لفحص **الجهة** (هـ/د-2)، أمّا **المقدار**
فاللفّة الكبيرة أدقّ — خطأ العين النسبي فيها أصغر. استعمال 90° هنا
يُضعف المعايرة، والسكربت صار يحذّر إن أعطيته زاوية صغيرة.

تُعلّم الاتجاه بشريط لاصق قبل اللفّ وبعده، وتقيس بمنقلة وتُدخل الرقم.
✅ النسبة المقترحة قرب 1.0 (±10%).
🔴 `⛔ دار عكس المطلوب` ⇒ خريطة المحركات، **لا إشارة الجايرو**.

### هـ-6 · بعد كل تعديل على config
```bash
python3 -m pi.tests.check_config_hygiene
python3 -m pi.nav.selftest        # المرجع: 420/427
```
🔴 الحارس يكشف: ثابتاً مُعرَّفاً مرتين (خللٌ وُجد فعلاً في `GYRO_SCALE`) ·
إرث منصّة ميتة · ثابتاً مشتقّاً كُتب رقماً.

## و) السيرفر والواجهة

```bash
cd ~/RMS-Rover-v2
RMS_ROVER_MODE=real ./run_server.sh
```
افتح: **`http://<عنوان-الراسبري>:8000`**

🔴 `RMS_ROVER_MODE=real` **إلزامي عند الإقلاع**: تبديل الوضع من الواجهة
لاحقاً **لا يعيد بناء مصدر الاتجاه**، فتبقى الملاحة على جايرو وهمي يوافق
الأوامر دائماً بينما الروبوت الحقيقي يفعل ما يشاء. والحاجب يكشفها:
«مصدر الاتجاه محاكى على جسر حقيقي».

راقب سطور الإقلاع (كل نظام فرعي باسمه وزمنه وحالته)، و`GET /api/boot`.

| في السجل | المعنى |
|---|---|
| `ناقل الروبوت: Freenove 4WD (PCA9685/I2C) (real)` | ✅ |
| `🔴 خريطة المحركات غير مشتقّة` | نفّذ (د-1) |
| `تعذّر فتح PCA9685` | ارجع إلى (ب) |

**القيادة اليدوية** من الواجهة — وهي **وضع التشغيل الآمن الوحيد** بلا
حساسات قرب. مهلة heartbeat **1.5ث** بلا أوامر ⇒ إيقاف المحركات.

## ترتيب أول جلسة

```
أ) setup_pi.sh → reboot → ls /dev/i2c-*
ب) i2cdetect -y 1 (40 و42) · -y 4 (68) → فحص الجسر بلا حركة
ج) العجلات مرفوعة → أمر السطر الواحد
د) probe_motor_map (مرفوع) → اكتب الثابتين → check_directions (أرضاً)
هـ) check_imu_health → sign → noise/drift → calibrate_speed → stage 2
و) RMS_ROVER_MODE=real ./run_server.sh → يدوي أولاً
```

⚠ **بين (ج) و(د) توقّف**: إن لم تدر العجلات الأربع، لا معنى لأي معايرة
بعدها — كل رقم سيُقاس على عطل.
