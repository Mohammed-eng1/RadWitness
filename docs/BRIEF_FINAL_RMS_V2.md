# BRIEF النهائي الشامل: RMS Rover v2 — روفر فحص إشعاعي ذاتي بقيادة راسبري باي

أنت تبني النسخة الثانية من روفر فحص إشعاعي ذاتي، وريثاً لمشروع سابق ناجح موجود في مجلد `legacy/` — **انهل منه ولا تعد الاختراع** (فيه: منطق جيجر معاير مخبرياً، واجهة ويب ناضجة، فيرموير شاشة، بروتوكولات موثقة). المنصة الجديدة: **راسبري باي 4 دماغاً مركزياً تتصل به كل الحساسات مباشرة**، وهيكل Wave Rover من Waveshare (**لم يصل بعد — كل شيء يُبنى ويُختبر مكتبياً بمحاكاته**).

## 1) المعمارية

```
[شاشة CYD: بوابة ميدانية AP + لمس] ←لورا 433MHz← ┐
[متصفح المستخدم] ←WiFi← [راسبري باي 4: كل الحساسات + AI + ويب + تسجيل]
                                  ↕ UART (بروتوكول Waveshare JSON)
                    [ESP32 مدمج في Wave Rover: محركات + IMU مدمج + سونار/IR]
```

**قاعدة توزيع الأمان (صلبة):** منطق النجاة الفوري لا يسكن الراسبري: مهلة توقف المحركات في ESP32 الروفر (فيرموير Waveshare يوفرها)، والراسبري قد يتجمد — النظام يفشل آمناً بدونه. أمر طوارئ من الشاشة عبر اللورا يجب أن يُعالج بأقصى أولوية فور وصوله للراسبري، وصمّم المسار بحيث فقدان heartbeat الراسبري عن الروفر > 1.5ث يوقف المحركات (وثّق الآلية في protocol.md).

## 2) العتاد والتوصيلات — كل الحساسات على الراسبري مباشرة

**قيود فيزيائية حرجة (كررها في wiring.md بتحذير بارز):**
1. **GPIO الراسبري يتحمل 3.3V فقط — 5V يتلفه فوراً.**
2. **لوحة الجيجر تُغذّى 3.3V** (وليس 5V) فتكون نبضاتها آمنة.
3. GND مشترك موزع على عدة دبابيس.

| القطعة | طرف القطعة | دبوس الراسبري (BCM / فيزيائي) | ملاحظة |
|---|---|---|---|
| جيجر 1 (CAJOE J305) | VIN نبضات | **GPIO21 / 40** | مقاطعة عبر lgpio · 📜 كان GPIO17/11 |
| جيجر 1 | تغذية / GND | 3.3V دبوس 1 / GND دبوس 9 | ⚠ 3.3V حصراً |
| جيجر 2 (عند وصوله) | VIN | GPIO27 / 13 | خلف علم SINGLE_TUBE_MODE |
| GPS NEO-M8N | TX | GPIO15 RXD / 10 | قراءة فقط، 9600 |
| GPS | VCC / GND | 5V دبوس 4 / GND دبوس 6 | منطقه 3.3V متوافق |
| BNO055 | SDA / SCL | GPIO2 / 3 و GPIO3 / 5 | عنوان 0x28، اكتشاف تلقائي 0x29 |
| BNO055 | VIN / GND | 3.3V دبوس 17 / GND دبوس 25 | |
| HC-14 لورا | عبر محول USB-Serial | منفذ USB → /dev/ttyUSB* | الخيار الموصى (أبسط من UART ثانٍ) |
| HC-14 | IPEX | كيبل UF.L→SMA → هوائي 433 | أبعده عن GPS |
| ويب كام | USB | أي منفذ | cv2.VideoCapture(0) |
| Wave Rover (عند وصوله) | UART اللوحة | GPIO14 TXD/8 ↔ RX، GPIO15... | ⚠ تعارض مع GPS — عيّن UART إضافية عبر dtoverlay ووثّقها |

ملاحظة IMU: عند وصول Wave Rover قد نتحول لـIMU المدمج فيه (QMI8658) — أبقِ BNO055 خلف واجهة تجريد بحيث التبديل قرار config، والمعيار: أيهما يعطي heading أثبت للمسح الدوراني.

## 3) طبقة البايثون على الراسبري — `pi/`

### 3.1 الحساسات (ابدأ بسكربتات اختبار منفردة في `pi/tests/` قبل أي دمج)
- **جيجر**: pigpio callback على الحافة، عدّاد + نافذة 30ث + EMA. **معايرة مخبرية مثبتة ضد Cs-137 انقلها من legacy**: `K = 111 CPM/(µSv/h)` + تصحيح زمن ميت `τ=200µs` (المعادلة في legacy/geiger.h). أبقِ `cpm_raw` بجانب المصحح. علم `HIGH_RATE_WARNING` في الواجهة فوق 30k CPM (قيد دقة لينكس عند المعدلات العالية — وثّقه بشفافية).
- **GPS**: pyserial + pynmea2 (أو gpsd) — fix, lat/lng, sats, hdop.
- **BNO055**: adafruit lib، heading مطلق، حالة معايرة (sys/gyro/accel/mag) تظهر في الواجهة مع تحذير mag<2.
- **ويب كام**: بث MJPEG في الواجهة + **لقطة تلقائية موسومة (وقت+إحداثيات+جرعة) عند كل شذوذ إشعاعي** تُحفظ في `captures/` وتظهر في سجل المهمة.
- **جسر Wave Rover**: واجهة تجريد بوضعين `real/sim`. sim (الافتراضي الآن): استجابة حركة واقعية، heading يتبع أوامر اللف، سونار وهمي. real لاحقاً: بروتوكول Waveshare JSON عبر UART.
- **لورا**: إطارات ≤60 بايت + checksum XOR (الصيغة في legacy/docs/protocol.md): يستقبل أوامر الشاشة ويبث لها تيليمتري مضغوطاً كل ثانية.

### 3.2 طبقة الذكاء (انقل المنطق من legacy C++ إلى بايثون)
- **anomaly**: معايرة خلفية 60ث عند بدء المهمة (Welford μ,σ)، كشف >μ+3σ يبث فوراً ويطلق لقطة الكاميرا.
- **risk**: التصنيف الخماسي على µSv/h: Safe<0.5 | Low 0.5-2 | Medium 2-10 | High 10-100 | Critical>100. عند Critical: أمر تراجع تلقائي + إنذار (خارج أي AI).
- **source_locator**: مسح دوراني 360° — 12 سلة×30° مربوطة بالـheading، زمن سلة قابل للضبط (افتراضي 15ث — مناسب لمصادر ضعيفة مثل KCl)، تنعيم دائري، ذروة + ثقة؛ لا نتيجة تحت عتبة الثقة (found:false أفضل من اتجاه مخترع). + تدرج الجرعة من آخر 16 نقطة GPS.
- **mission**: محرك waypoints (bearing من GPS + تصحيح heading، وصول <3م) + مولّد مسح شبكي lawnmower من مستطيل على الخريطة + RTH (يدوي/فقدان القنوات/بطارية) + تقرير نهاية JSON (أعلى جرعة وموقعها، اتجاه المصدر وثقته، مناطق الخطر، توصيات عربية بقواعد صريحة، روابط لقطات الشذوذ).
- **الكابتن**: دردشة في الواجهة تخطط المهمات عبر Anthropic API — **النداء من متصفح المستخدم (المفتاح لا يلمس الراسبري)**، النموذج ملزم بإخراج خطة JSON بقيود فيزيائية (سرعة/بطارية/مدة)، الخطة تُرسم على الخريطة **وتُعتمد بشرياً** قبل الحفظ في مكتبة المهمات (`missions/`)، والتنفيذ لاحقاً بلا إنترنت. أوامر الدردشة التشغيلية من قائمة مسموحة فقط + تأكيد المستخدم.

### 3.3 سيرفر الويب (FastAPI + WebSocket)
انقل روح واجهة legacy (ثيم داكن، خريطة Leaflet بخريطة حرارية دوائر ملونة + سهم اتجاه المصدر بطول=الثقة + سهم التدرج، عداد جرعة دائري بلون الخطر، رسم CPM زمني، طقطقة WebAudio بمعدل CPM، لوحة صحة المكونات، بث الكاميرا) مع:
- **لوحة أزرار كاملة — لا كونسول أبداً**: بدء/إنهاء مهمة (بمؤشر تقدم المعايرة)، مسح 360/إيقاف، RTH وطوارئ (بتأكيد)، تنزيل تقرير/سجل، إنذار تجريبي، Ping لورا بعرض RTT، اختيار مهمة من المكتبة وتنفيذها. أزرار محاكاة (قفزة شذوذ مفتعلة) تظهر في وضع sim فقط. كل زر بfeedback فوري.
- **زر إيقاف آمن**: shutdown نظيف للراسبري (حماية كرت SD) بعد تأكيد.
- التسجيل: كتابة مجمّعة دورية (كل 10-30ث) لسجل المهمة CSV — أعمدة تشمل `cpm_raw,cpm,usvh,risk,anomaly,lat,lng,heading,capture_file`.

## 4) فيرموير الشاشة — `firmware/controller_display/` (البوابة الميدانية)
انقل من legacy وكيّف: اللوحة ESP32-3248S035R افتراضياً (ST7796، 320×480، لمس XPT2046، إضاءة IO27 بـPWM 60%، HC-14 على RX=IO35/TX=IO22) + علم `BOARD_CYD_28` للبديلة 2.8".
- **AP** باسم `RMS-CONTROL` + **Captive Portal** (DNSServer — أي عنوان يفتح الصفحة تلقائياً).
- صفحة self-contained في PROGMEM، **ممنوع CDN**: أزرار قيادة لمسية + سرعة، جرعة بلون الخطر، heading/GPS مختصر، أزرار مهمة أساسية، حالة لورا + Ping RTT. لا كاميرا (لورا لا يحمل فيديو).
- واجهة TFT لمسية: شاشتا قيادة وتيليمتري، تحديث على مؤقّت 250ms (لا مع كل حزمة).
- heartbeat 400ms أثناء ضغط أزرار الحركة من أي واجهة.

## 5) مراحل التنفيذ — المكتب أولاً (الروبوت غائب)
- **M0**: بند 0 (git) + شجرة المشروع + سكربتات اختبار الحساسات المنفردة.
- **M1**: سيرفر + واجهة أساسية + جسر روفر sim يُقاد على الخريطة.
- **M2**: جيجر حقيقي → الواجهة (بالمعايرة المنقولة) + طبقة الذكاء + المهمة الكاملة بالأزرار.
- **M3**: ويب كام (بث + لقطة الشذوذ) + GPS حقيقي + BNO055.
- **M4**: لورا (راسبري↔الشاشة) + فيرموير الشاشة كاملاً.
- **M5**: الكابتن + مخطط المهمات + المكتبة + التقارير.
- **M6** (عند وصول Wave Rover): جسر real + معايرة قيادة + failsafe نهائي + جداول توصيل الروفر.

بعد كل مرحلة: توقف، ملخص، وخطوات اختبار سريعة على العتاد قبل التالية.
