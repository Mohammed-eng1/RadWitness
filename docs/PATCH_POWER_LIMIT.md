# PATCH: حدّ القوة الصارم + قيم المعايرة المحدّثة (بطارية ممتلئة)

تعديل عاجل على RMS Rover v2 بناءً على اكتشاف مقاس على العتاد.

## 1) اكتشاف حرج: التفاف القوة في فيرموير Wave Rover

مسح تجريبي لقيم القوة (بطارية ممتلئة، سيراميك، 2 ثانية لكل قيمة) كشف **تجاوزاً عددياً (wrap-around)**: أي قيمة فوق 0.5 يُطرح منها 0.5 في الفيرموير.

| القوة المرسلة | السرعة المقاسة | القوة الفعّالة |
|---|---|---|
| 0.2 | 0.250 م/ث | 0.2 ✓ |
| 0.4 | 0.590 م/ث | 0.4 ✓ |
| 0.5 | 0.750 م/ث | 0.5 ✓ |
| 0.6 | **0.100 م/ث** | 0.1 (0.6−0.5) |
| 0.8 | **0.410 م/ث** | 0.3 (0.8−0.5) |
| 1.0 | **0.750 م/ث** | 0.5 (1.0−0.5) |

**الخطر**: إرسال 0.6 توقعاً لسرعة أعلى ينتج زحفاً بطيئاً، بينما يحسب `deadreckoning` المسافة على أساس السرعة المتوقعة → انحراف كبير في تقدير الموقع **بلا أي إنذار**.

### المطلوب

- في `config.py`: `MAX_MOTOR_POWER = 0.5` مع تعليق يشرح السبب (تجاوز عددي مثبت تجريبياً — لا تغيّره دون إعادة قياس).
- في `pi/rover/bridge.py`: **حاجز صارم قبل كل إرسال** — قصّ أي قيمة إلى النطاق `[-0.5, 0.5]` مع الحفاظ على الإشارة، وسجّل تحذيراً (`logger.warning`) عند وقوع القص، وابثّه في سجل أحداث الواجهة. الحاجز يُطبَّق **بعد** `MOTOR_INVERT` ويشمل كل مسارات الإرسال (تقدّم، رجوع، لفّ، أوامر الواجهة اليدوية).
- أضف اختباراً في `selftest` يتحقق أن `motors(0.8, 0.8)` يُرسل فعلياً 0.5 ويُنتج تحذيراً.

## 2) قيم المعايرة المحدّثة — تحلّ محل القديمة

القيم السابقة أُخذت تحت بطارية منخفضة (~10.1V) وهي **متقادمة**. المعايرة الجديدة (بطارية ممتلئة، سيراميك):

| القوة | السرعة |
|---|---|
| 0.2 | 0.250 م/ث |
| 0.4 | 0.590 م/ث |
| 0.5 | 0.750 م/ث |

- العلاقة خطية تقريباً: **السرعة ≈ 1.5 × القوة** (صالحة داخل 0.1–0.5 فقط). استخدم استيفاءً خطياً بين النقاط المقاسة، ولا تستقرئ خارج النطاق.
- الفارق عن المعايرة القديمة ~25% عند نفس القوة — دليل على أهمية تسجيل الجهد مع كل معايرة (الميزة موجودة في `calibration.py`، تأكد أنها تُملأ).
- احفظها كملف معايرة افتراضي باسم "سيراميك — بطارية ممتلئة".

## 3) إعادة تعريف سلّم السرعة داخل النطاق الصالح

استبدل `SPEED_LADDER` السابق (كان يتجاوز 0.5):

```python
SPEED_LADDER = [      # (أبعد من X سم → القوة)
    (150, 0.50),      # طريق مفتوح  (~0.75 م/ث)
    (80,  0.40),      # اقتراب      (~0.59 م/ث)
    (45,  0.30),      # حذر         (~0.45 م/ث)
    (30,  0.20),      # زحف         (~0.25 م/ث)
]
SPEED_NO_READING = 0.25
DRIVE_POWER_DEFAULT = 0.40    # سرعة المهمة الافتراضية
```

`TURN_POWER = 0.40` يبقى (داخل النطاق الآمن).

## 4) توثيق

- أضف قسماً في `docs/wiring.md` أو `docs/protocol.md` بعنوان "قيود فيرموير Wave Rover" يذكر التفاف القوة بجدول القياسات أعلاه — معلومة غير موثّقة رسمياً واكتُشفت تجريبياً.
- حدّث `CLAUDE.md` بقاعدة: **لا تُرسل قوة > 0.5 لأي محرك مطلقاً**.
