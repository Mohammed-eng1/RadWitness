# BRIEF M1+M2: دمج الحساسات في السيرفر والواجهة الحية

المرحلة M0 اكتملت: مستودع Git جاهز، والحساسات الثلاثة **مختبرة ومثبتة على العتاد الحقيقي** بسكربتات منفردة في `pi/tests/`. المطلوب الآن: دمجها في سيرفر ويب واحد بواجهة حية، تُفتح محلياً وعبر Tailscale.

## القيم المثبتة على العتاد — استخدمها حرفياً، لا تخمّن ولا تعدّل

هذه قيم مؤكدة تجريبياً على منصة الراسبري الفعلية (Debian trixie)، أي انحراف عنها يكسر القراءة:

1. **المنصة: lgpio** (وليس pigpio — محذوف في trixie). كل تعامل GPIO عبر lgpio.
2. **الجيجر**: **BCM21 (دبوس 40)** 📜 كان BCM17 حتى 2026-09-13، `lgpio.RISING_EDGE`، **بلا أي مقاومة `lgpio.SET_PULL_NONE`** (عائم — مخرج CAJOE عالي الممانعة؛ أي pull داخلي يقتل الإشارة → CPM=0). السطر الحرفي المثبت:
   ```python
   lgpio.gpio_claim_alert(h, 17, lgpio.RISING_EDGE, lgpio.SET_PULL_NONE)
   ```
3. **BNO055**: I2C على العنوان **0x29** (وليس 0x28 الافتراضي). heading موثوق بعد أن يبلغ mag≥2.
4. **GPS**: `/dev/serial0`، NMEA، قفل مؤكد (6-7 أقمار، HDOP~3).
5. **الكاميرا**: `/dev/video0`، 640×480.
6. المعايرة: **K=111 CPM/(µSv/h)** + تصحيح زمن ميت **τ=200µs** (Cs-137 مخبري — ثوابت لا تُغيَّر).

انقل منطق كل حساس من سكربتات `pi/tests/` المثبتة إلى وحدات `pi/sensors/` بلا تغيير في القيم أعلاه.

## M1 — السيرفر والهيكل

- **FastAPI + WebSocket** على المنفذ 8000 (يُفتح محلياً وعبر Tailscale: `http://therover:8000`).
- **حلقة قراءة الحساسات** async غير حاجبة: الجيجر (callback lgpio مستمر + نافذة 30ث + EMA)، GPS وBNO055 وكل ثانية، الكاميرا عند الطلب.
- **بث WebSocket** كل ثانية: JSON موحّد `{cpm_raw, cpm, usvh, risk, lat, lng, sats, hdop, heading, mag_cal, ...}`.
- **جسر Wave Rover** خلف واجهة تجريد `real/sim` — sim الافتراضي الآن (الروبوت لم يصل): يحاكي استجابة الحركة وheading يتبع الأوامر.
- **بنية الوحدات**: `pi/sensors/{geiger,gps,imu,camera}.py`, `pi/web/server.py`, `pi/rover/bridge.py`.

## M2 — الواجهة الحية + طبقة الذكاء

**الواجهة** (انقل روح واجهة legacy: ثيم داكن، خريطة Leaflet، عداد جرعة ملون):
- عداد جرعة دائري بلون مستوى الخطر + بطاقات CPM (خام ومصحح)/µSv/h/GPS/heading/أقمار.
- خريطة Leaflet: موقع الروفر حي + أثر المسار + (لاحقاً) خريطة حرارية وسهم المصدر.
- رسم CPM زمني (canvas خفيف، بلا CDN — قد نعمل عبر Tailscale بلا إنترنت كامل).
- لوحة صحة المكونات: جيجر/GPS/IMU (مع مؤشرات معايرة BNO055 الأربعة + تحذير mag<2)/كاميرا.
- بث الكاميرا (MJPEG) عند الطلب.
- طقطقة WebAudio بمعدل CPM الحي.
- **أزرار لا كونسول**: بدء/إنهاء مهمة، قيادة sim (اتجاهات + سرعة)، إيقاف طوارئ، تنزيل CSV.

**طبقة الذكاء** (بايثون، من منطق legacy):
- معايرة خلفية 60ث (Welford μ,σ) عند بدء المهمة، كشف شذوذ >μ+3σ يبث فوراً.
- التصنيف الخماسي على µSv/h (Safe<0.5 | Low 0.5-2 | Medium 2-10 | High 10-100 | Critical>100).
- تسجيل مجمّع دوري (10-30ث) لـ`logs/` وسجل المهمة لـ`missions/`: أعمدة `time,cpm_raw,cpm,usvh,risk,anomaly,lat,lng,heading`.

- [ ] لا استيراد لـpigpio في أي ملف (lgpio حصراً).
